カセットテープ・メモリイメージ

対応フォーマット

  • .cmt — バイト列そのままのテープイメージ
  • .t88 — データキャリアタグ付きテープイメージ

テープのマウント

操作ショートカット
テープ > 開く...⇧⌘T
テープ > 巻き戻し—
テープ > 取り出し—

テープをマウントすると、ステータスバーにテープアイコンと現在のテープ名が表示されます（設定 > 表示 > ステータスバー > テープアイコンを表示 が有効なとき）。

画面に .cmt / .t88 をドラッグ＆ドロップしても開けます。ZIP などのアーカイブはディスクとして開くので、テープ > 開く... を使ってください。

読み込み手順

  1. ブートモードを V1H（もしくは V1S）にして N88-BASIC プロンプトを出します。
  2. テープ > 開く... から .cmt または .t88 を選択。
  3. BASIC に LOAD "CAS:" + Return を入力。
  4. 読み込みが終わり Ok に戻ったら RUN + Return。

自動起動

テープ > 自動起動 にチェックを入れると、テープを開く（最近使ったファイル を含む）たびに、ディスクと CD を排出し、V1S モード・4MHz でリセットしたあと、LOAD "CAS:" の入力、読み込みの完了待ち、RUN の入力までを自動で行います。チェックは次回起動時も保たれます。

途中で止めるには esc を押します。エラーが出たときや、読み込みが始まらないときは RUN を入力せずに止まります。ブートモードとクロックは V1S・4MHz のままになります。

動作音

モーターの回転音とリレー音は、設定 > オーディオ > FDD/CMTサウンドを有効にする に従って再生します。

最近使ったテープ

テープ > 最近使ったファイル から、最近開いたテープを最大 10 件までたどれます。

既知の制限

  • テープへの書き込み（SAVE "CAS:" など）には対応していません。BASIC は Syntax error にはなりませんが、テープには何も記録されません。
  • 波形タイミングに依存するプロテクトが掛かったテープは読み込めないことがあります。

メモリイメージ

コントロール > メモリイメージを開く... で PC-8001 のメモリイメージ（.n80）を読み込み、N モード・4MHz で起動します。ウインドウへのドラッグ＆ドロップでも開けます。
