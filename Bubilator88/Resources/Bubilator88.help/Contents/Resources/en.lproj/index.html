Bubilator88 Help

Bubilator88 is a macOS emulator for the NEC PC-8801 series.

  • CD-ROM — The PC-8801MC CD-ROM drive, CD images (cue / ccd) and CD audio
  • Keyboard — Key mapping, layouts, special key assignment, software keyboard, and romaji kana input
  • Display — Window scaling, Video Filter, translation overlay, and screenshots
  • Audio — Volume, Audio Buffer, FDD/CMT Sound, Pseudo Stereo, CD Mix, and Immersive Audio
  • Save States — Quick Save / Load, 30 slots, what gets saved, and Rewind
  • Game Controller — Controller connection, button mapping, and haptics
  • Mouse — Bus mouse / joystick mode, capturing and releasing the pointer, and sensitivity

  • Keyboard Shortcuts — Keyboard shortcuts and turbo controls
