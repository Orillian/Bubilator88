Keyboard Layout

Choose Auto-detect, JIS, or US (ANSI) in Settings > Keyboard > Keyboard Layout. When Auto-detect is selected, the current detected layout is shown.

In JIS mode, several symbol keys are remapped to match JIS keycaps. For example, JIS @, [, and ] go to the matching PC-8801 keys.

Numpad Emulation

For keyboards without a physical numpad, three options are available in Settings > Keyboard:

  • Arrow Keys as Numpad — Maps arrow keys to numpad 2/4/6/8 for game character movement.
  • Number Row as Numpad — Maps the number row (0-9) to numpad 0-9 for games that only accept numpad input (e.g., adventure game menus).
  • WASD as Numpad — Maps W/A/S/D to numpad 8/4/2/6 for left-hand character movement.

Software Keyboard

View > Software Keyboard (⇧⌘K) opens an on-screen keyboard laid out like the PC-8801's. Clicking a key types it exactly as pressing the real key would.

Click SHIFT / CTRL / GRPH / KANA / CAPS once to apply it to the next key only, or double-click to hold it down until you click it again. While KANA, SHIFT, or GRPH is active, the keycaps show their kana, shifted, or graphic-character legends.

Romaji Kana Input

Turn on Control > Romaji Kana Input (⌥⌘K) to type half-width katakana by entering romaji.

Backspace deletes one letter of an unconverted syllable, and ESC cancels the input in progress. Other keys — digits, punctuation, Return and so on — are sent to the PC-8801 unchanged.
