Cassette Tape and Memory Images

Supported Formats

  • .cmt — raw byte-stream tape image
  • .t88 — tape image with data-carrier tags

Mounting a Tape

CommandShortcut
Tape > Open...⇧⌘T
Tape > Rewind—
Tape > Eject—

When a tape is mounted, the status bar shows a tape icon together with the current tape name (requires Settings > Display > Status Bar > Show Tape Icon).

You can also drop a .cmt or .t88 on the screen. A dropped archive such as a ZIP opens as a disk, so use Tape > Open... for those.

Loading a Program

  1. Set Boot Mode to V1H (or V1S) so the N88-BASIC prompt appears.
  2. Choose a .cmt or .t88 file via Tape > Open....
  3. Type LOAD "CAS:" + Return in BASIC.
  4. When loading completes and Ok returns, type RUN + Return.

Auto Boot

Turn on Tape > Auto Boot and every tape you open (Recent Files included) will eject the disks and the CD, reset into V1S mode at 4MHz, type LOAD "CAS:", wait for the load to finish and type RUN, all by itself. The setting is remembered between launches.

Press esc to stop it midway. It stops without typing RUN if BASIC reports an error or the load never starts. The boot mode and the clock stay at V1S and 4MHz afterwards.

Operation Sound

The motor whir and relay click follow Settings > Audio > Enable FDD/CMT Sound.

Recent Tapes

Tape > Recent Files keeps up to 10 of your most recently opened tapes.

Known Limitations

  • Writing to tape (SAVE "CAS:" and friends) is not supported. BASIC won't raise a Syntax error, but nothing is written to the tape.
  • Tapes with waveform-timing based copy protection may fail to load.

Memory Images

Control > Open Memory Image... loads a PC-8001 memory image (.n80) and starts it in N mode at 4MHz. You can also drop one on the window.
