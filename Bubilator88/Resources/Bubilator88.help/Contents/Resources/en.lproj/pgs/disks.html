Using Disks

Supported Formats

Bubilator88 can open the following files:

  • D88 disk images (.d88, .d77, .2d, .2hd)
  • M3U playlists (.m3u, .m3u8)
  • ZIP, LZH, CAB, RAR, and 7z archives (when they contain D88 disk images)

It also supports D88 files that contain multiple disk images.

Some RAR variants need unar, unrar, or 7z installed on your Mac.

Mounting Disks

MenuShortcut
Disk > Drive 1 > Mount...⌘1
Disk > Drive 2 > Mount...⌘2
Disk > Drive 1&2 > Mount...⌘3

You can also drag and drop a file onto the emulation screen. Dropped files are mounted in Drive 1&2 mode.

Multiple Images and Archives

If the selected file contains multiple disk images, a picker sheet appears before mounting. After mounting, you can switch images from Disk > Drive 1 / Drive 2 or from the status-bar drive menus.

Drive 1&2 > Mount... assigns the first image to Drive 1 and the second image to Drive 2. If there is no second image, Drive 2 stays empty.

If an archive contains multiple disk files, you first choose which file to open.

Playlists

Multi-disk titles can be opened from an .m3u / .m3u8 playlist that lists the disk images, one path per line. Blank lines and lines starting with # are ignored, and relative paths are resolved against the playlist's own folder.

Opened in Drive 1&2 mode, the first entry goes to Drive 1 and the second to Drive 2. When opened into a single drive, only the first entry is used.

Creating Blank Disks

Use Disk > Create Blank Disk... (⇧⌘N) to create a formatted blank D88 image. After saving, the new disk is mounted automatically in Drive 1.

  • 2D (320KB) — Single-sided double-density
  • 2DD (640KB) — Double-sided double-density (default)
  • 2HD (1.2MB) — Double-sided high-density

Write Protection

Disk > Drive 1 / Drive 2 > Write Protect blocks writes to the mounted disk, just like the tab on a real floppy. A check mark appears in the menu while it is on, and writes from the software fail.

Writing Back to Disk

When software writes to a disk (saving a game, for example), the change is written back to the original D88 file automatically, about 0.1 seconds after the writes stop. There is no setting for this; it is always on. Ejecting a disk, quitting the app, and loading a save state write back immediately.

Turn on Write Protect for disks whose original file you do not want modified.

Disks inside an archive (ZIP / LZH / CAB / RAR / 7z) are written back to the cache extracted on first mount. The original archive is never modified.

If no write-back destination can be determined, or the write fails, the disk is saved as a recovery D88 in ~/Library/Application Support/Bubilator88/ModifiedDisks/.

Exporting Cached Disks

Disk > Export Cached Disks... copies D88 files from the archive cache into a folder of your choice. Check Only disks whose original archive is missing to export just the disks whose source archive has been moved or deleted.

Ejecting and Recent Files

Use Disk > Drive 1 > Eject or Disk > Drive 2 > Eject to remove a disk.

Disk > Recent Files stores up to 10 recently opened files. Choosing one mounts it again in Drive 1&2 mode.
