Control from AI Tools

AI tools that support MCP (Model Context Protocol) can control Bubilator88 while it runs. Ask in plain words for something like "boot this disk and get to the title screen", and the AI presses the keys, runs the emulator and checks the screen.

What the AI Can Do

AreaDescription
RunningReset, run a given number of frames, run until text appears or the screen settles, pause and resume
InputPress keys, type text, record and replay input
Screen and soundTake screenshots, read the text screen, check that sound is playing and record it to WAV
MediaInsert and eject disks, CDs and tapes, boot tapes, load memory images, write-protect disks, save and load states
DevelopmentRead and write registers and memory, disassemble, set breakpoints, watch memory writes, and time code

What the AI does shows on the screen and in the debugger window as it happens.

Examples

Ask the AI tool in everyday words. Here are some things you can ask for.

Starting and Playing a Game

AskWhat the AI does
"Put ~/Games/foo.d88 in drive 1, boot it, and show me the title screen."Mounts the disk, resets, runs frames while checking the screen, and returns a screenshot of the title screen
"Enter BUBIO on the name screen and start the game."Checks the screen for the entry field, types the name and presses RETURN
"I'm right before the boss. Save a state."Saves a .b88s file where you say. Ask "load that state" later to go back
"Read the message on the screen and summarize it in English."Reads the text screen. Text drawn as graphics is read from a screenshot
"Insert ~/CD/game.cue and boot it."Inserts the CD and boots from it. Needs CDBIOS.ROM
"Take the CD out and boot from the disk again."Ejects the CD and resets. A CD in the drive boots ahead of the disks, so the AI checks for one first
"How many disks are in ~/Games/bar.d88? Put the second one in drive 2."Lists the disks in the file and mounts the one you name
"Check that the music is actually playing."Records the sound for a while and reports its level for FM, SSG, ADPCM, rhythm and CD. It can also save a WAV file

Using BASIC

AskWhat the AI does
"Type in an N88-BASIC program that draws ten circles, and run it."Writes the program, types it on the keyboard, enters RUN and checks the result on screen
"Load this tape (~/Tapes/bar.cmt) and run it."Mounts the tape, types LOAD "CAS:" and RUN as Tape > Auto Boot does, and runs until loading finishes
"Load ~/Mem/baz.n80."Restarts in N-BASIC, restores the PC-8001 memory image and types RUN if it needs it
"If there's an error, find the cause, fix it and run it again."Reads the error message on screen, retypes the line and runs the program

Recording and Replaying Input

AskWhat the AI does
"Record from here to ~/rec/stage1.b88s and play until stage 1 is cleared."Saves the current state, records the input, and adds it to the same file when done
"Replay stage1.b88s and show me the last screen."Replays the recorded input on the same frames to reproduce the same scene

Analyzing and Developing Programs

AskWhat the AI does
"Find where the number of lives is kept and set it to 99."Compares memory before and after losing a life to find the address, then writes the new value
"Find the code that draws this part of the screen."Tracks memory writes and looks up the instruction and address that last wrote there
"Load my assembled ~/src/game.bin, stop at MAIN from the symbol file, and show the registers."Loads the machine code into RAM, reads the symbols, sets a breakpoint, and returns the registers and disassembly where it stops
"Measure how many T-states the drawing routine uses per frame."Times the given stretch of code and reports the count, total, longest and mean

Setting It Up

  1. In Settings > General > AI Tool Control (MCP), turn on Allow control from AI tools.
  2. Under Register With, choose the AI tool you use.
  3. Click Copy and register the command or settings shown, as the note below them says.
  4. Start a new session in the AI tool.
Register WithHow
Claude Code, Gemini CLI, GitHub Copilot (VS Code)Run the command in Terminal
Codex CLIAdd it to ~/.codex/config.toml
PiAdd it to ~/.pi/agent/mcp.json, then run /reload in Pi
opencodeAdd it to ~/.config/opencode/opencode.json
CursorAdd it to ~/.cursor/mcp.json
Other (JSON)Paste it into the AI tool's MCP settings, or paste it to the AI and ask it to add it

The text can be edited. If an AI tool has changed how it is registered, fix the text before copying it.

With the Develop menu shown, Develop > Allow Control from AI Tools turns it on and off too. The setting is kept across launches.

Tips

  • Give full paths — Name disks and states by a location starting with ~/ or /Users/….
  • The emulator pauses while the AI works — The AI runs the emulator as many frames as it needs, as fast as it can, and stops there. To play on yourself, ask it to "run in real time" or choose Emulator > Resume (⌘P).
  • Say when to stop — Ask for something like "run until the title screen" or "wait for it to finish loading", and the AI runs in one go until the text appears or the screen settles.
  • No kanji — The AI can type letters, digits, symbols and half-width katakana.
  • Reading the screen — Text on the text screen is read exactly. Text drawn as graphics, and pictures, the AI judges by looking at a screenshot.

Port and Safety

  • Only this Mac can connect.
  • The port starts at 18801. If another app uses it, change it and register again with your AI tools.
  • The registration text holds the password (token) for connecting. Do not show it to others.
  • The AI reads and writes disk and state files at the paths it gives. Turn it off when you are not using it.

If It Does Not Connect

  • Check that Bubilator88 is running and Allow control from AI tools is on.
  • Check that you started a new session in the AI tool after registering.
  • If you changed the port, register again with the AI tool.
