Control from AI Tools

AI tools that support MCP (Model Context Protocol) can control Bubilator88 while it runs. Ask for something like "boot this disk and get to the title screen", and the AI presses the keys, runs the emulator and checks the screen.

What the AI Can Do

AreaDescription
RunningReset, run a given number of frames, pause and resume
InputPress keys, type text, record and replay input
ScreenTake screenshots and read the text screen
MediaMount disks and tapes, save and load states
DevelopmentRead and write registers and memory, disassemble, set breakpoints, watch memory writes, and time code

What the AI does shows on the screen and in the debugger window as it happens.

Setting It Up

  1. In Settings > General > AI Tool Control (MCP), turn on Allow control from AI tools.
  2. Under Register With, choose the AI tool you use.
  3. Click Copy and register the command or settings shown, as the note below them says.
  4. Start a new session in the AI tool.
Register WithHow
Claude Code, Gemini CLI, GitHub Copilot (VS Code)Run the command in Terminal
Codex CLIAdd it to ~/.codex/config.toml
PiAdd it to ~/.pi/agent/mcp.json, then run /reload in Pi
opencodeAdd it to ~/.config/opencode/opencode.json
CursorAdd it to ~/.cursor/mcp.json
Other (JSON)Paste it into the AI tool's MCP settings, or paste it to the AI and ask it to add it

The text can be edited. If an AI tool has changed how it is registered, fix the text before copying it.

With the Develop menu shown, Develop > Allow Control from AI Tools turns it on and off too. The setting is kept across launches.

Port and Safety

  • Only this Mac can connect.
  • The port starts at 18801. If another app uses it, change it and register again with your AI tools.
  • The registration text holds the password (token) for connecting. Do not show it to others.
  • The AI reads and writes disk and state files at the paths it gives. Turn it off when you are not using it.
